# Security / Responsible publication

This repository currently contains **documentation only** for a defensive Windows USB forensic research prototype. No original application code, screenshots, device logs, TOTP secrets or evidence databases are included in the scaffold.

Avoid committing or opening issues with private identifiers, device serial numbers, Windows Event Logs, Registry dumps, SetupAPI logs, secrets, backup codes, TOTP provisioning QR codes, personal data or screenshots revealing these.

Before reproducing device blocking in the original application, use only hardware and Windows test systems you own or are explicitly authorized to test; verify recovery access. Administrative privileges are required for some functions.

For a security concern regarding a future public release, contact the repository owner privately through the profile's existing contact links. Do not post exploitation details or credentials in public issues.
